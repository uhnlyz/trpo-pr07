# Практическая работа № 7 — PHP MVC интернет-магазин

## Результат
Каркас учебного интернет-магазина на PHP: единая точка входа, Router, два контроллера и представления. Маршруты загружаются из `dataset/routes.csv`, данные главной страницы — из `dataset/pages.json`.

## Запуск
Нужен PHP 8.0 или новее. Из корня проекта:
```bash
php -S localhost:8000 -t public
```
Откройте http://localhost:8000.

## Маршруты
| Адрес | Контроллер | Представление |
|---|---|---|
| / | HomeController | home/index.php |
| /catalog | CatalogController | catalog/index.php |

Неизвестный адрес возвращает страницу 404 и HTTP-статус 404.

## Структура
```text
dataset/       исходные CSV и JSON
public/        точка входа и CSS
src/Core/      Router
src/Controller контроллеры
views/         layout и страницы
```

## Проверка
Откройте главную страницу, каталог и адрес /unknown. Главная использует поля из pages.json, каталог пока показывает три тестовых товара. Чтение данных и выбор маршрута выполняются до подключения представления.

## Ограничения
Каталог содержит временный массив товаров. Модели и репозиторий будут добавлены в следующей работе. Это учебный каркас без базы данных и оформления реальных заказов.
